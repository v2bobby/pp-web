# PurePalate — Landing Page

Premium landing page for PurePalate (White + Orange theme).

## Features
- Modern white + vibrant orange design
- Fully responsive
- Animated hero headline with staggered entrance
- Boxed/sectioned layout
- Waitlist form with success state
- Production-ready code

## Quick Start

### Local Development
Just open `index.html` in any browser.

### Deploy to Vercel (Recommended)

1. Push this folder to GitHub
2. Import the repository on [Vercel](https://vercel.com)
3. Vercel will automatically detect it as a static site

Or deploy instantly with Vercel CLI:

```bash
npm i -g vercel
vercel
```

## Files
- `index.html` — Main landing page
- `styles.css` — All styling + animations
- `script.js` — Form handling + mobile menu
- `assets/logo.svg` — Brand logo
- `vercel.json` — Vercel deployment config

## Customization
- Change accent color in CSS (`--accent`)
- Update founder details in the Founder section
- Modify waitlist form behavior in `script.js`

Built with care for a premium feel.
